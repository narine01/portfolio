# Laxmy Narayan, Portfolio

Next.js static site. All content lives in `data/content.js`.

## Run locally
    npm install
    npm run dev        # http://localhost:3000

## Deploy free on Vercel
1. Push this folder to a new GitHub repo.
2. Go to vercel.com, sign in with GitHub, click "Add New > Project", pick the repo.
3. Keep the defaults (Framework: Next.js) and click Deploy.
4. You get a free `your-project.vercel.app` URL. Every `git push` redeploys.

Custom domain: Project > Settings > Domains (the domain itself costs money; hosting is free).

## Update your resume
Replace `public/Laxmy_Narayan_Resume.pdf` with the new file, keeping the same name.
